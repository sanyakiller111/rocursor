# Проверка сборки

Короткая версия: всё, что делает приложение, видно в исходниках. Три файла —
это весь код:

| Файл | Что внутри | Объём |
|---|---|---|
| `cursor_core.py` | вся работа с Roblox: поиск папки, бэкап, подмена, восстановление | 228 строк |
| `cursor_library.py` | каталог курсоров: вшитый набор + автообновление | 420 строк |
| `roblox_cursor_changer.py` | интерфейс | 390 строк |

Суммарно меньше тысячи строк. Прочитать можно целиком.

## Что приложение делает с вашим компьютером

**Читает:**

```
%LOCALAPPDATA%\Roblox\Versions\version-*\content\textures\Cursors\KeyboardMouse\
    ArrowCursor.png
    ArrowFarCursor.png
    MouseLockedCursor.png
```

Ищет эту папку в `LOCALAPPDATA`, `Program Files`, `Program Files (x86)`.
Если нашёл несколько версий — берёт ту, где лежит `RobloxPlayerBeta.exe`,
иначе самую свежую по дате изменения.

**Пишет:**

```
%APPDATA%\RobloxCursorChanger\        настройки, индекс каталога, кэш картинок
%APPDATA%\RobloxCursorChanger\backup\ копии оригинальных текстур Roblox
```

Из папки Roblox — только три PNG-файла курсора. Ничего больше.

**Не делает:**

- не запрашивает логин или пароль Roblox
- не читает cookies браузера
- не трогает токены Discord
- не изменяет исполняемые файлы Roblox
- не работает в фоне после закрытия окна
- не собирает телеметрию

Проверить отсутствие сетевого обмена кроме каталога курсоров можно так:

```bash
grep -rn "requests\.\|urllib\|socket\.\|http" --include="*.py" .
```

В `cursor_core.py` — только `osuskinner.com`. В `cursor_library.py` — только
URL из `version.CATALOG_URL`, который по умолчанию пуст.

## Как проверить .exe

### 1. Хеш

Рядом с релизом лежит `SHA256SUMS`:

```bash
sha256sum -c SHA256SUMS
```

Либо в PowerShell:

```powershell
Get-FileHash .\sanyakiller111.exe -Algorithm SHA256
```

Строка в приложении, раздел «О приложении» → «SHA-256 сборки», должна совпасть.

### 2. Пересобрать самому и сравнить

Самый сильный аргумент. Если ваша сборка даёт тот же хеш — вы получили
именно тот код, что лежит в репозитории.

```bash
git clone https://github.com/sanyakiller111/sanyakiller111-cursor-manager
cd sanyakiller111-cursor-manager
python tools/make_assets.py
build.bat
```

Побайтовое совпадение воспроизводится, если совпадают версия Python, PyInstaller
и Pillow — они зафиксированы в `requirements-build.txt`.

### 3. VirusTotal

Сборка загружается в релиз. Ссылка на отчёт — в разделе «О приложении».
Не нужно верить автору: ссылка ведёт на публичный отчёт, который читают все.

## Почему onefile

Приложение собирается как один `sanyakiller111.exe`, чтобы его не приходилось
искать и собирать из папки. Такой exe при запуске распаковывает себя во
временную папку, и некоторые антивирусы относятся к этому настороженно —
поэтому проверяйте хеш (выше) и подпись, когда она появится. Установщик
кладёт тот же файл в `%LOCALAPPDATA%\Programs\sanyakiller111`.
Подробности в `docs/BUILD.md`.

## Подпись

Приложение распространяется с подписью Authenticode (стандартный OV-сертификат,
~$99–400 в год; EV не нужен — с 2024 года он не даёт преимущества в SmartScreen).

Сертификат требует аппаратного хранения ключа: с июня 2023 CA/Browser Forum
запрещает скачиваемые `.pfx` для публично доверенных сертификатов. Есть
USB-токен или облачная подпись.

Пока сертификата нет, у сборки нет подписи. Это не делает её опасной — она
просто вызывает SmartScreen при первом запуске. SHA-256 и открытый исходник
остаются проверяемыми.
